# Security Policy

## Supported versions

Security fixes are provided for the latest published AppleTree release (Mac App
Store and GitHub Releases).

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public GitHub issue.

Use **Security → Report a vulnerability** on this repository. That opens a
private report visible only to the reporter and maintainers. Include:

- A description of the issue and its potential impact
- Reproduction steps or a proof of concept
- The affected AppleTree version and macOS version
- Any suggested mitigation

You can expect an initial acknowledgment within seven days. Confirmed issues
will be evaluated, fixed, and disclosed with an appropriate release when
necessary.

Ordinary bugs and feature requests still belong in GitHub Issues — see
[`CONTRIBUTING.md`](CONTRIBUTING.md).
